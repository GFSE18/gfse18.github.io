Metal 3D Printing Heated Build Plate Validation

As an AMPF researcher from Aug 2025 to Apr 2026, I validated a heated build plate for directed energy deposition through finite element analysis and instrumented cold testing.

Validation approach
The project investigated thermal-cycle-driven residual stress, delamination, and cracking in metal additive manufacturing.

Selected work

  • Built and evaluated finite element models of the heated build plate.
  • Designed cold tests using machined stainless-steel weights.
  • Instrumented the setup with hand-soldered strain gauges to compare measured and predicted behavior.
